ROUTE 1 / DP03

知道世界规则，
就在模型里规划。

DP 的前提不是“数据很多”，而是你明确知道：做动作后，环境以什么概率转移、给什么奖励。

Vₖ₊₁(s) ← Σₐ π(a|s) Σₛ′,ᵣ p(s′,r|s,a)[r+γVₖ(s′)]Policy evaluation：固定策略 π，对全部后继做期望 backup。
+

优势

没有环境采样噪声；小型状态空间能得到精确基准。

−

限制

需要完整模型，还要遍历状态空间；现实机器人、LLM 环境通常做不到。

→

为什么仍要学

它是所有 Bellman backup 最干净的原型。

已知世界 · 做期望03 / 07
ROUTE 2 / MC04

不猜未来，
等整局结果发生。

Monte Carlo 不需要 P。不依赖下一个状态价值，只把已经走完的真实折扣回报 Gₜ 当作 target。

V(s) ← V(s) + 1/N(s) · [Gₜ − V(s)]本质是不断维护从状态 s 出发的完整回报样本均值。
好处

target 不 bootstrap，不会直接把后继估计错误写进目标。

代价

必须等 episode 结束；长任务 credit assignment 慢。

统计特征

完整 Gₜ 受随机未来影响，通常高方差。

走完整局 · 做平均04 / 07
ROUTE 3 / TD05

走一步，
就开始校正价值。

TD 看见一条 transition 就更新。看不到整局的未来？用对下一状态的当前估计补上。

V(sₜ) ← V(sₜ) + α[rₜ₊₁ + γV(sₜ₊₁) − V(sₜ)]方括号是 TD error：一步 target 与当前预测的差。
⚡

能在线学习

每条 transition 都能更新，不必等终局。

↻

这叫 bootstrap

target 的一部分来自自己的 V(s′) 估计。

!

代价

后继估计的偏差会通过 backup 传播。

走一步 · 用估计补未来05 / 07
