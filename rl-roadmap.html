01 / THE MAP

先建立“问题地图”，再学习算法。

强化学习不是一串算法名。它研究的是：智能体在不确定环境中采取行动、延迟获得反馈，并最大化长期回报。每一种算法都在回答三个问题：如何估值、如何探索、如何稳定地更新策略。

01 · MODEL

环境转移已知吗？已知时可以规划；未知时只能通过样本估计。

02 · DATA

数据来自当前策略、历史日志，还是可验证的 rollout？这决定偏差和稳定性。

03 · OBJECTIVE

最大化什么回报、如何定义 reward、怎样约束策略变化，决定真正被优化的行为。

A

表格型 RL：理解学习信号

Value Iteration、Monte Carlo、SARSA、Q-learning。环境小到可以看见每个 (Q(s,a)) 如何变化。

产出：Bellman backup 图、收敛曲线、最优策略。
B

深度 RL：处理高维状态

DQN、Double/Dueling DQN、PPO、SAC。理解神经网络近似如何带来不稳定、过估计和样本效率问题。

产出：消融表、seed 方差、learning curve。
C

长时程决策：模型、离线数据与多智能体

World Model、Offline RL、Decision Transformer、CTDE。重点变成分布外动作和 imagined rollout 是否可信。

产出：offline score、OOD 风险、world-model error。
D

LLM / Agent RL：把环境变成可验证任务

Reward model、PPO、DPO、RLOO、GRPO、工具调用与 multi-turn agent。核心问题是 reward、rollout、评估器和系统吞吐的共同设计。

产出：pass@k、reward、KL、rollout cost、真实任务成功率。

02 / MATHEMATICAL CORE

所有路线都从同一条反馈方程出发。

先把 MDP 写清楚：状态 (s)、动作 (a)、转移 (P(s'|s,a))、奖励 (r)、折扣 (gamma)。目标是最大化期望折扣回报，而不是只追逐眼前 reward。

G_t = Σₖ₌₀∞ γᵏ rₜ₊ₖ₊₁ 回报：未来奖励的折扣和。γ 越小，策略越偏好近处回报。
Vᵖ(s) = Eₚ[ rₜ₊₁ + γVᵖ(sₜ₊₁) | sₜ = s ] Bellman expectation equation：当前价值 = 一步奖励 + 下一状态价值。
Q(s,a) ← Q(s,a) + α [ r + γ maxₐ′ Q(s′,a′) − Q(s,a) ] Q-learning 的 TD error 就是方括号。它用一次交互样本替代未知的转移期望。

规划 vs. 学习

规划已知环境模型，直接对 Bellman 方程反复 backup；学习不知道 (P)，从 sample backup 逼近相同固定点。A1 用 GridWorld 把二者放在同一环境对照。

on-policy vs. off-policy

on-policy用当前行为策略收集并优化当前策略，如 PPO；off-policy可以复用历史数据，如 DQN、SAC。收益是样本效率，代价是分布偏移与稳定性难题。

学习检查点

在进入 DQN 前，必须能解释：为什么低 (gamma) 改变的是“任务偏好”而不是“训练速度”；为什么 (epsilon) 衰减太快会造成局部最优；以及 TD target 中哪些量应该 stop-gradient。

03 / ALGORITHM FAMILIES

算法选择，本质是偏差、方差、样本效率的交换。

不要从“哪个算法最新”开始。先判断动作空间、是否可重放历史数据、是否能安全在线探索、以及是否具备环境模型。

VALUE-BASED

DQN → Double / Dueling / Rainbow

离散动作。用 replay buffer 打破时间相关性，用 target network 稳定 bootstrap；Double DQN 抑制 max 操作的过估计。

POLICY GRADIENT

REINFORCE → TRPO → PPO

直接优化策略。PPO 用 clipped objective 限制单次更新过大，是理解 RLHF 的重要入口。

ACTOR–CRITIC

A2C / DDPG / TD3 / SAC

actor 选择动作，critic 估值。SAC 通过熵正则化保留探索，在连续控制中具备高样本效率。

MODEL / DATA-DRIVEN

MuZero · Dreamer · Offline RL

学习环境动力学或直接从固定日志学习。关键风险是 model error 和 distributional shift，而非单纯 reward 不够高。

04 / FRONTIER CONNECTIONS

前沿不是脱离基础的新名词。

LLM 后训练和 Agent 训练仍然是 RL，只是状态变成 token / trajectory，环境可能是代码解释器、检索工具或浏览器，奖励可能来自 verifier 或偏好模型。

LLM 的 PPO loop

  • 从 prompt 分布采样 response trajectory。
  • reward model 或 verifier 给分。
  • 估计 advantage，加入 KL 约束以不偏离 reference model。
  • 多轮 minibatch 更新 policy，同时监控 reward 与 KL 是否失控。

GRPO 的直觉

  • 对同一个 prompt 采样一组输出。
  • 用组内相对 reward 构造 advantage，减少依赖独立 value critic。
  • 尤其适合 reward 可以自动验证的推理任务。
  • 仍需警惕 reward saturation、长度偏置和 verifier 漏洞。

05 / EVIDENCE, NOT VIBES

没有对照和方差，曲线不构成结论。

RL 的随机性很强。一个 seed 的最终 reward 不能说明算法更好；每一个实验都要记录配置、随机种子、环境版本、预算、均值与离散程度。

阶段最低实验纪律不应得出的结论
Tabular RL至少 3 个 seed；报告成功率、步数、return；画策略图。“收敛了，所以参数最优。”
Deep RL5–10 个 seed；固定环境与 step budget；报告 median / IQR 或置信区间。“最后一个点更高，所以方法更好。”
Offline RL固定数据集版本；区分 in-distribution 与 OOD；报告 normalized score。“训练 loss 更低，所以行为更优。”
LLM RL固定 prompt/eval set；分离训练 reward 与 held-out task metric；报告 rollout token 成本。“reward 上升，所以模型更有用。”
