RL COLLECTION / 02 / ESTIMATION

价值与 Bellman：
怎样把很长的未来压缩成一步？

这一课把 Lesson 01 的 return 变成可学习的对象。核心不是背方程，而是理解每一次 backup 都在做一件事：用“眼前 + 对下一步的估计”修正今天的判断。

THE PROBLEM

回报 G 很准确，为什么还需要 value？

一条完整 episode 的回报 Gₜ 告诉我们“这次从 t 开始最终拿到了多少”。但在真正做决策时，它有三个困难：未来还没发生；同一状态会走向多个不同结局；若每次都等整局结束，长任务会非常慢。

核心转变

价值函数不是一次轨迹的结果，而是对从某个条件出发、未来长期回报的期望。它把大量可能未来压缩成一个可比较的数。

Return Gₜ

一条真实样本轨迹上已经实现的折扣奖励和。它会受随机性影响，方差较大。

Value V 或 Q

给定策略后的条件期望。它是估计，不必等待完整未来，因此能指导当前动作。

TWO QUESTIONS

V(s) 与 Q(s,a) 分别在回答什么？

先固定一个策略 π。策略可以是“到路口一律向右”，也可以是在每个状态输出动作概率分布。此时有两种最常用的估值问题：

函数它问的问题定义什么时候更顺手
状态价值 Vπ(s)“已经来到 s，之后按 π 行动，平均还能拿多少？”Vπ(s) = Eπ[Gₜ | sₜ=s]需要评估一个既定策略，或用 Critic 判断状态好坏。
动作价值 Qπ(s,a)“在 s 先做 a，之后按 π 行动，平均还能拿多少？”Qπ(s,a) = Eπ[Gₜ | sₜ=s, aₜ=a]需要直接比较当前候选动作，或做 Q-learning 控制。

注意 Vπ(s) 与 Qπ(s,a) 都带 π：策略变了，未来行动方式变了，价值也会变。只有在“最优策略”语境下，才写 V*(s)、Q*(s,a)。

THE RECURSION

Bellman 方程不是魔法，它只是把 G 拆开。

Lesson 01 的定义是 Gₜ = rₜ₊₁ + γrₜ₊₂ + γ²rₜ₊₃ + …。把括号移动一次：

Gₜ = rₜ₊₁ + γ(rₜ₊₂ + γrₜ₊₃ + …) = rₜ₊₁ + γGₜ₊₁“现在开始的回报”恰好等于“一步奖励 + 折扣后的下一时刻回报”。这就是所有 Bellman 关系的源头。

对随机未来取条件期望，并假定之后按 π 行动，就得到 Bellman expectation equation：

Vπ(s) = Σₐ π(a|s) Σs′,r p(s′,r | s,a) [r + γVπ(s′)]第一层求和：策略在 s 可能选哪些动作；第二层求和：环境对该动作可能返回哪些下一状态与奖励。确定性环境里，这些加权平均会退化成一条路径。

因此 Bellman equation 不是一个新假设，而是 return 定义、马尔可夫状态与全期望公式共同推出的递归恒等式。

ONE BACKUP

一次 backup 到底更新了什么？

想象某状态 s 只有一次“向右”动作：立刻 reward=2，抵达 s′；当前估计 V(s′)=5，γ=0.9。Bellman target 是：

target = 2 + 0.9 × 5 = 6.5不是说 s 的真实价值一定是 6.5；而是在“下一状态估值 V(s′) 目前可信”的前提下，它给当前 V(s) 的一条一步训练信号。

若当前 V(s)=4.0，则TD error δ = target − V(s) = 2.5。用步长 α 更新：V(s) ← V(s) + αδ。α=0.2 时，新的 V(s)=4.5；我们没有“相信一次样本到底”，而是向 target 移动一小步。

EVALUATION VS CONTROL

先评估固定策略，再谈如何变得更好。

问题已知 / 固定的东西所求典型符号
Policy evaluation（评估）策略 π 不变。这条策略各状态有多好？Vπ、Qπ
Control（控制）允许改变策略。怎样找到价值最高的策略？V*、Q*、π*

Bellman optimality equation 对应第二种问题。它不再按固定 π 做平均，而是直接比较最好的动作：

V*(s) = maxₐ Σs′,r p(s′,r | s,a)[r + γV*(s′)]
Q*(s,a) = E[r + γ maxa′Q*(s′,a′)]max 的含义是“假设从下一步起总能选择最优动作”。这也是 Q-learning 看起来为何带有 max 的根源。
先别混淆

“取策略平均”对应 evaluation；“取最大动作”对应 optimal control。SARSA、Q-learning、Actor-Critic 的区别会在后续课里围绕：谁产生数据、target 里到底用当前策略还是最优动作、如何减少估计偏差。

WHAT CAN GO WRONG

Bellman target 也会错，而且会自我传播。

BOOTSTRAP BIAS

target 使用 V(s′) 或 Q(s′,a′) 的估计；若后继估计有偏差，偏差会沿 backup 反向传递。

SAMPLE NOISE

单次 r、s′ 只是环境分布的一个样本。随机环境中，必须多次更新来逼近期望。

FUNCTION APPROXIMATION

用神经网络共享参数时，更新一个状态会影响别处估计；这正是深度 RL 稳定性难题的入口。

所以“Bellman 方程成立”不等于“任何实现都会稳定收敛”。它给出正确的固定点；如何从有限、相关、带噪样本接近固定点，是后续算法设计的主战场。

CHECK YOUR UNDERSTANDING

先自己推，再展开答案。

01 · 为什么 Vπ(s) 不能简单等于 maxaQπ(s,a)？

因为 Vπ 评估的是固定策略 π 的实际后续行为，它应按 π(a|s) 对 Qπ(s,a) 加权平均。只有最优策略对应的 V*(s) 才与 maxaQ*(s,a) 相等。

02 · 已知 r=1、γ=0.8、V(s′)=10、V(s)=6，TD error 是多少？

target = 1 + 0.8×10 = 9；δ = 9−6 = 3。正误差表示当前 V(s) 低估了这个一步 target。

03 · 为什么 Bellman backup 能在 episode 尚未结束时更新？

它用 r + γV(s′) 代替未知的完整 Gₜ；也就是用对后继的当前估计 bootstrap。代价是引入估计偏差，收益是不必等到终局。
