RL COLLECTION / 01 / FOUNDATIONS

MDP 与长期回报：
强化学习到底在学什么？

这一课不写训练代码。目标是建立一张正确的心智图：智能体不是在拟合标签，而是在行动后改变未来会看到的数据与奖励。

THE QUESTION

为什么“预测下一个标签”不足以描述 RL？

监督学习通常假设训练数据已经给定：输入 x 对应标签 y，模型减少预测误差即可。强化学习中，动作会影响下一个状态；当前为了拿到小 reward 的选择，可能损失未来更大的 reward。数据分布不是固定的，而是策略自己参与生成的。

核心对象

一个决策过程由状态 s、动作 a、转移规律 P、奖励 r 与折扣 γ 描述。我们把它称为马尔可夫决策过程，MDP。

THE LOOP

一条 trajectory 是怎样产生的？

策略 π 看到状态后选择动作；环境返回 reward 和新状态。连续的交互记录为 trajectory (τ)。算法的不同之处，往往只是“如何利用这些 trajectory 估计长期好坏”。

THE OBJECTIVE

reward 不是目标；长期回报才是。

某一时刻的 reward 只是局部信号。强化学习定义从时刻 t 开始的折扣回报：

Gₜ = rₜ₊₁ + γrₜ₊₂ + γ²rₜ₊₃ + …γ ∈ [0,1) 是 discount factor。γ 接近 1 时更重视远期后果；γ 较小时更偏好快速兑现的奖励。
短视策略

现在拿到 +1，但之后连续 8 步得到 -1。若只看即时 reward，它看起来很诱人。

长视策略

先经历若干步成本，之后抵达 +10 终点。是否值得，取决于完整 return 与 γ，而非“终点 reward 更大”这一句直觉。

IMPORTANT DISTINCTION

当 A2 中 γ=0.5 的智能体偏向近处终点时，它并不必然“训练坏了”。它可能正是在正确优化一个更短视的目标函数。调参前先确认：你想改变的是学习过程，还是任务定义本身？

THE MARKOV ASSUMPTION

为什么状态要“足够”描述过去？

MDP 假设：给定当前状态和动作，未来与更早历史独立。形式上：

P(sₜ₊₁ | sₜ, aₜ, sₜ₋₁, aₜ₋₁, …) = P(sₜ₊₁ | sₜ, aₜ)这不是说历史永远无用；而是说 state 的定义应当包含影响未来的必要信息。

若智能体看不到关键变量，例如扑克中对手的底牌、机器人被遮挡的速度，问题更接近 POMDP。实践中会通过历史窗口、RNN、Transformer 或 belief state 去近似“足够的状态”。
