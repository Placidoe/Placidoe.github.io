RL COLLECTION / GLOSSARY

强化学习
名词速查

不默认你已经懂术语。每张卡只做三件事：一句定义、它为什么重要、一个直观例子。新术语会持续补充。

HOW TO USE

遇到陌生词，先回到它在交互闭环中的位置。

大多数 RL 术语属于四类：谁在行动、看见了什么、如何评价好坏、怎样从经验中更新。不要背定义；把术语放回“Agent → Action → Environment → Reward / Next State”的循环里。

INTERACTION

谁与谁交互？

AGENT / 智能体

做决定的一方

接收信息、选择动作、根据反馈调整行为的程序或模型。

例子：玩 Atari 的控制器、机械臂控制网络、会调用工具的 LLM agent。

ENVIRONMENT / 环境

被行动影响的世界

接收动作，返回下一步信息和奖励的系统；可以是游戏、仿真器、代码执行器或浏览器任务。

例子：GridWorld 根据“向右走”返回新格子和 reward。

STATE / 状态 s

决策所需的“充分信息”

如果知道当前状态和动作，就足以描述未来的概率分布，那么它是 Markov state。

例子：棋盘局面通常比“刚才下了什么棋”更接近状态。

OBSERVATION / 观测 o

Agent 实际看得到的输入

观测不一定等于真实状态；它可能缺少隐藏信息，因此任务可能是部分可观测的。

例子：摄像头画面看不到机器人被遮挡的速度。

ACTION / 动作 a

Agent 对环境施加的选择

动作可以是离散的，也可以是连续向量；动作空间决定可用算法。

例子：GridWorld 的上/下/左/右；机械臂每个关节的力矩。

REWARD / 即时奖励 r

环境给出的局部反馈

它是每一步的信号，不等于最终目标；reward 设计会直接改变被优化的行为。

例子：抵达终点 +10、每走一步 -1，鼓励更短路径。

DATA & OBJECTIVE

一段经验怎样变成“长期好坏”？

TRAJECTORY / 轨迹 τ

一次连续交互记录

由状态、动作、奖励不断交替形成的数据序列，是 RL 的基本训练材料。

例子：(s₀,a₀,r₁,s₁,a₁,r₂, …)。

EPISODE / 回合

有开始和结束的一段轨迹

通常在成功、失败、超时或达到终止状态后结束；并非所有任务都天然分回合。

例子：走到 GridWorld 终点，或 CartPole 倒下。

POLICY / 策略 π

从状态到动作的规则

策略可以确定性地选一个动作，也可以输出动作分布。训练的最终产物通常就是它。

例子：π(右|当前位置)=0.8，π(上|当前位置)=0.2。

RETURN / 回报 G

从现在开始的长期奖励

未来 reward 的折扣和。优化 return，才会让智能体权衡短期成本与远期收益。

例子：现在 -1、以后 +10，是否值得要看完整 G。

DISCOUNT / 折扣 γ

未来 reward 的权重

γ 接近 1 更重视长期后果；减小 γ 不只是“让训练更稳”，也会改变优化目标。

例子：A2 中 γ=0.5 会理性偏向较近的收益。

MDP / 马尔可夫决策过程

RL 的最小问题描述

由状态、动作、转移概率、奖励和折扣组成。它规定“环境是什么”和“好坏如何定义”。

例子：GridWorld：格子、移动规则、终点奖励与 γ。

LEARNING SIGNALS

算法在估计什么，又靠什么更新？

VALUE / 状态价值 V(s)

处于一个状态有多好

在遵循某个策略的前提下，从状态开始可获得的期望 return。

例子：离目标近不一定价值高，还要考虑陷阱和未来路径。

Q-VALUE / 动作价值 Q(s,a)

在状态 s 做动作 a 有多好

它把“选择哪个动作”的比较显式化，Q-learning 因而可以直接选 max Q 的动作。

例子：同一格子中，向右与向上有不同 Q 值。

BELLMAN BACKUP

用下一步估计当前步

当前价值 = 当前 reward + 折扣后的下一状态价值。它将长期问题递归拆解。

例子：Q(s,a) 用 r + γ max Q(s′,a′) 作为学习目标。

TD ERROR / 时序差分误差 δ

预测和新目标之间的差

δ = r + γV(s′) − V(s)。它是“我原先对未来的估计错了多少”。

例子：若意外拿到高 reward，δ 为正，相关价值会上调。

EXPLORATION / 探索

主动尝试尚不确定的动作

不探索就可能永远不知道更好的路径；探索过多又会牺牲即时表现。

例子：ε-greedy 以 ε 的概率随机行动。

EXPLOITATION / 利用

选择当前估计最好的动作

利用已有知识拿 reward；它与探索共同构成经典张力。

例子：选择当前 Q(s,a) 最大的动作。
