THE RULE

先开始，不把“前置知识”变成拖延。

RL 课程最常见的失败路径是两种极端：一类人把所有公式硬背下来；另一类人因为觉得数学不够而永远不开始。正确做法是按需补齐：遇到一个概念时，知道它在解决什么问题、最小定义是什么、何时需要更严谨的版本。

本课程原则

Lesson 01–04 的 tabular RL 不要求微积分或深度学习；你只需会四则运算、理解“概率”和“平均”。向深度 RL、policy gradient 推进时，再打开线性代数、导数和优化这几扇门。

MICRO MATH 01

概率与期望：RL 最早需要的数学。

若环境有两种结果，不是简单地选“最常见的一个”，而是看每个结果的价值乘以它出现的概率。例如向右后，80% 到好格子、20% 滑到坏格子：

E[return] = 0.8 × 10 + 0.2 × (−5) = 7E 是 expectation（期望）。它不是承诺“每一次都得到 7”，而是大量重复时的平均。

这正是 Bellman 方程里 Σ p(·) 的含义：把所有可能下一步的价值按发生概率做加权平均。若环境完全确定，概率为 1 的那一项留下，其余项为 0，公式就退化成一条普通路径。

一分钟自检

抛硬币正面得 +2、反面得 −2，公平硬币的期望是 0。这不表示每次 reward 都是 0；它表示你无法仅靠重复这一动作获得长期平均正收益。

MICRO MATH 02

向量、函数与梯度：等到 Deep RL 再深入。

在 tabular RL，我们可以直接存一张表：每个状态一个 V(s)。状态很多时，表放不下，于是用神经网络函数 Vθ(s) 近似它；θ 是网络里所有可调参数。

loss(θ) = [target − Vθ(s)]²
θ ← θ − η ∇θloss(θ)第一行说“预测离 target 有多远”；第二行说“按让 loss 下降最快的方向微调参数”。η 是 learning rate，∇ 是梯度。

你现在只要建立这个因果链：输入状态 → 网络输出估值 → 与 target 比较 → 调参数减少误差。Lesson 05 会把向量、矩阵和反向传播完整拆开；在此之前，不会默认你懂它们。
