Deep RL 前的最小数学

WHY THIS EXISTS

表格为什么会变成神经网络？

tabular RL 可以存一张表：每个状态一个 V(s) 或每个状态动作对一个 Q(s,a)。图像、文本、连续传感器的可能状态几乎无穷，表装不下；于是我们用带参数的函数去近似它：

Vθ(s) 或 Qθ(s,a)θ（theta）是函数/神经网络中全部可调数字。它的目标是让相似输入得到合理、可泛化的估值。

G2 · VECTOR

向量就是有顺序的一串数字。

状态可以写成向量 x。例如 CartPole 可近似表示为 x=[位置, 速度, 杆角度, 角速度]。模型不理解这些中文名字，它只对数值做变换。

x=[2,3]，w=[0.5,−1]
w·x = 0.5×2 + (−1)×3 = −2点积是对应位置相乘后求和。最简单的线性预测可以写作 ŷ=w·x+b。
对象直觉Deep RL 中的例子
标量 scalar一个数。reward、loss、一个 Q 值。
向量 vector有顺序的一串数。一个状态、一条动作、一个 embedding。
矩阵 matrix把许多向量变换成新向量的一张数表。一层网络权重、一个 batch 的状态。
张量 tensor更高维的一组数，不必神秘化。图像 batch、Transformer 激活、PyTorch 数据容器。

G3 · LOSS

优化前，必须先定义“错了多少”。

一条 TD transition 可能给出 target=6.5，而网络预测 Qθ(s,a)=4.0。一个简单的平方误差：

loss(θ) = [target − Qθ(s,a)]² = (6.5−4.0)² = 6.25loss 是训练信号，不是环境 reward。reward 定义任务好坏；loss 衡量当前参数是否拟合训练 target。
四个数，四种角色

reward：环境的单步反馈；return：长期任务目标；value：对 return 的估计；loss：更新参数时最小化的工程目标。它们都像“分数”，却不能互换。

G3 · GRADIENT

梯度回答：参数往哪个方向动，loss 会下降？

只有一个参数 θ 时，导数 d loss/dθ 表示 θ 微小变化时 loss 的变化率。多个参数时，把每个偏导排成向量，就是梯度 ∇θloss。

θ ← θ − η∇θloss(θ)η（eta）是 learning rate。梯度指向 loss 增长最快处，沿负梯度才是局部下降方向。

若 θ=4，某一步导数为 +3，η=0.1，则新 θ=4−0.1×3=3.7。导数为正说明继续增大 θ 会让 loss 变大，所以更新把它往小的方向推。

THE WHOLE LOOP

把一次 Deep RL 更新翻译成人话。

后面 DQN 的 replay buffer、target network 和 double Q 都是在保护这个循环：减少样本相关、让 target 慢一点变化、缓解最大化偏差。

CODE READING

不要求现在会写，但要读懂四行。

prediction = q_net(state, action)  # Qθ(s,a)
target = reward + gamma * max_q(next_state)
loss = (target - prediction).pow(2).mean()
optimizer.step()  # 沿负梯度更新 θ

真实 PyTorch 会多出 batch、replay、target network；但复杂实现都能还原成这四行的因果链。

CHECK YOUR UNDERSTANDING

先分清四个角色。

01 · reward=+1 但 loss 很大，矛盾吗？

不矛盾。+1 是环境反馈；loss 大表示网络对当前 TD target 的预测还不准。两者来自不同层面。

02 · 为什么不能把每个新状态塞进无限大的 V 表？

连续状态、图像、文本组合的数量极大或无穷。函数近似用参数共享，希望从已见状态泛化到相似未见状态。

03 · learning rate η 太大可能怎样？

每次参数跨得太远，可能越过低点、震荡甚至发散；太小则收敛很慢。它改变学习过程，不改变环境任务定义。
